## 📖 Description

A full-stack E-commerce web application designed for a premium perfume store.  
Built using the MERN stack, this project includes secure Google OAuth authentication and Stripe payment integration.  
Users can browse, search, filter, and purchase products with ease on a fully responsive interface.


## 🚀 Features

- 🔐 Google OAuth 2.0 Authentication (Secure Login)
- 💳 Stripe Integration for Seamless Payments
- 🔍 Advanced Product Search, Filtering & Pagination
- 🛒 Add to Cart, Checkout Flow & Order Confirmation
- 📱 Fully Responsive UI with Tailwind CSS
- 🔧 RESTful API built with Express.js & MongoDB
- 📦 Dynamic Product Management from Database
- 🌐 Deployed for public access (if applicable)
